20. CRC-16 多項式長除法

題目描述解題思路範例追蹤完整程式碼與解釋易錯點自我檢查

01 / 題目到底要做什麼？

（10%）對 8-bit message 計算 CRC-16，生成多項式 x^16+x^12+x^5+1=0x11021；依題意在訊息後補十六個零，以 GF(2) 多項式長除法取餘數。輸入 [0x10]，輸出高 byte [0x00]、低 byte [0x01]，輸入保留。此解參數為 MSB-first、seed=0、不反射、無 final XOR。各題須單獨組譯，不能把九題連結在一起；EQU 僅定義固定 RAM 符號而不保留記憶體。Access 模式不能直接存取任意 bank，跨 bank 陣列須用 FSR。

02 / 從題意推導程式

  1. 初始化 CRC=message<<8，低 byte 清零，做八次移位。此表示法已等價完成 message<<16 的長除法，不要再多做十六輪。
  2. 清 C，先 RLCF 低位再高位，C 保存移出前的 bit15。
  3. 若舊最高位為一，以 XOR 0x1021 消去多項式最高項；最高 x^16 已由 Carry 表示，因此只存低十六位。
  4. GF(2) 的減法是 XOR，不是 SUBWF；多項式相同不代表任意 CRC 函式庫預設都相同。

05 / 最容易踩的坑

  • 檢查的是移出前最高位所留下的 Carry，不是左移後的 bit15。
  • 不能額外跑 16 輪，否則等同追加更多零。
  • 0x11021 有十七位；寫入兩個 byte 的 0x1021 並非漏項。

06 / 確認自己真的懂了

為何 XOR 而不是減法？

多項式係數在 GF(2)，加減都以 XOR 完成。

輸出是否包含 message？

否，只輸出兩個 CRC byte。
