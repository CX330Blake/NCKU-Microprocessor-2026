18. 相同四個 hexadecimal digits 的下一個排列

題目描述解題思路範例追蹤完整程式碼與解釋易錯點自我檢查

01 / 題目到底要做什麼？

（5%）輸入 unsigned 16-bit [0x10]:[0x11]，重新排列它的四個十六進位數字，求嚴格大於原值且最小者，輸出 [0x00]:[0x01]，均高位在前。四位包含前導零及重複數字，輸入保持不變。額外 SUCCESS=[0x20] 是解答自訂，不是考題要求；無解時原題未定義輸出，本碼約定保留輸入且 SUCCESS=0，不循環至最小排列。各題須單獨組譯，不能把九題連結在一起；EQU 僅定義固定 RAM 符號而不保留記憶體。Access 模式不能直接存取任意 bank，跨 bank 陣列須用 FSR。

02 / 從題意推導程式

  1. 拆出四個 nibble d[0..3]，由右尋找第一個 d[i]<d[i+1] 的 pivot。
  2. 找不到 pivot 表示全串非遞增，已是最大排列。
  3. pivot 右側後綴為非遞增；從最右找嚴格大於 pivot 的數字，就是可用的最小較大數字。交換兩者。
  4. 反轉 pivot 後綴使其非遞減，再組回兩個 byte。保留最多高位、最小幅度增加 pivot、最小化後綴，三步保證下一個排列。

05 / 最容易踩的坑

  • 固定交換末兩位不能處理非遞增後綴。
  • 排序全部數字只會得到最小排列，不保證比原值大。
  • SUCCESS 與無解保留原值都是本解約定，不能當成原題規格。

06 / 確認自己真的懂了

為何從後綴最右找較大數字？

後綴非遞增，所以最右的合格者是最小較大值。

完全相同的四位有下一個排列嗎？

沒有嚴格較大的值。
